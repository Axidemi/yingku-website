MADE FOR YOUR MOVIES

把注意力，留给电影。

从播放的基本功开始，逐步完善你的媒体库。

01 / PLAYBACK

双内核，更多播放选择。

AVFoundation 与 VLCKit 配合，接入 MP4、MOV、MKV 等格式。支持自动、硬解优先和软件解码，切换时保留播放进度。

MKVMP4 / MOV软硬解切换
02 / IMMERSION

需要时出现，观影时退场。

全屏闲置 3 秒后隐藏控制栏，鼠标活动时唤回。键盘支持暂停、跳转、音量、字幕与音轨切换。

Space←→F
03 / COLLECTION

为收藏，找回封面。

接入 TMDB 电影搜索，按片名和年份匹配海报与简介。支持批量补齐、手动选片与本地海报缓存，需要自行配置 Token。

海报刮削离线缓存
04 / SUBTITLES

看得懂，也调得顺手。

切换音轨与内嵌字幕，导入外挂 SRT，调整字幕延迟、字号和亮度。在线字幕搜索接入 OpenSubtitles，需要自行配置凭证。

SRT字幕延迟多音轨

INDEPENDENT & PERSONAL

你的影片，
你的媒体库。

映库是一个独立开发的个人媒体播放器，目前用于非商业开发与个人使用。它不提供影视内容，也不分发影片资源。

在线海报匹配会向 TMDB 发送搜索片名；凭证保存在系统钥匙串。开发预览尚未公开发行，目前没有公开下载版本。

This product uses the TMDB API but is not endorsed or certified by TMDB.
